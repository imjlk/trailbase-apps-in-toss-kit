Keep the RN account check when stored sessions move to WebView. `ait-web/storage` adds `createAppsInTossWebSessionStorage`, which wraps `ait.storage` with the same guard as the RN session storage. It reads the `${appKey}.appSession`, `${appKey}.tossSession` and `${appKey}.anonymousHash` keys the RN bundle wrote. When the Toss account on the device changed, it clears both sessions and returns null instead of restoring another account's session. The anonymous hash only detects an account change; WebView authentication still exchanges a fresh code. A session saved before any account is recorded, such as `adoptAppSession` on a first launch, now records the current account first, so the next read keeps it instead of discarding it. That lookup gives up after 10 seconds: the save rejects without writing, so a stalled SDK call cannot hold a later logout clear or save after it. With `revalidateAnonymousHash` (the WebView default), the account check and session cleanup run as one queued step, so a delayed check from an earlier read can no longer clear a session saved after the account switched. The RN guard now lives in `ait-core`; RN sessions get the same two fixes and are otherwise unchanged. The migration map no longer suggests reading session keys through plain `ait.storage`.

`check-consumer-webview-migration.mjs` now ignores imports inside comments, strings and template text, and finds imports with comments between their tokens, inside template `${...}` expressions and in escaped specifiers. It tells division from regex literals after `++`, `--` and statement conditions, even with long comments before the condition, and restores quoted import names. It reports type-only imports for manual review instead of runtime guidance. It rejects a missing or non-directory `--root` with exit code 2. Unreadable directories, unparsable `package.json` files and source files over 2 MiB are listed as `scanIssues`, and `--strict` fails while any remain. The text report now prints file paths and each module's migration note, including for namespace and other unclassified imports.
