# TrailBase v0.35.7

- 게시 시각: 2026-10-28T20:26:24Z
- 릴리스 URL: https://github.com/trailbaseio/trailbase/releases/tag/v0.35.7

## 릴리스 노트

- 브라우저에서 더 많은 SSE 스트림을 다중화할 수 있도록 HTTP/2 협상을 활성화했습니다.
- WASM SQLite 확장 함수 런타임을 WASM HTTP handler와 분리하고 구현을 정리했습니다. SQLite 함수 초기화에 바이너리 버전을 올바르게 전달합니다.
- 리소스를 더 일찍 해제하도록 종료 순서를 개선했습니다.
- 의존성을 업데이트했습니다.
