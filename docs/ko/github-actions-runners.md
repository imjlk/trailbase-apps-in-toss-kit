# 비공개 컨슈머 GitHub Actions 러너

컨슈머 CI를 선택적으로 자체 호스팅하려면 복사해서 사용하는 [러너 템플릿](../../templates/github-runner/README-ko.md)을 적용합니다. 앱 배포 Compose와 별도이며, 키트 gitlink나 TrailBase 서버를 변경할 필요가 없습니다.

개인 GitHub 계정은 저장소마다 러너를 등록하고, 필요하면 여러 컨테이너를 Coolify 서비스 하나로 묶습니다. 러너 하나를 여러 저장소가 공유하는 방식은 조직 범위에서 지원됩니다. 저장소별 자격 증명, 등록 정보, 작업 경로를 유지하고 공개 저장소나 신뢰하지 않는 PR은 GitHub 기본 러너를 사용합니다.

공통 도우미는 BuildKit 자원 제한, 이미지 로딩, 공유 임시 경로를 확인합니다. Docker 통합 테스트는 활성화 전에 로컬 접속, 고유 이름을 통한 정리, 자원 제한을 검토해야 합니다. 호스트 Docker 접근은 서버 관리 권한이며 자원 제한이 이를 격리하지 않습니다.

등록과 실제 실행을 검증하기 전까지 활성화 변수를 false로 둡니다. 재시작 후 등록 정보 유지도 확인하고, 각 컨슈머의 릴리스와 업로드 정책을 보존합니다.
